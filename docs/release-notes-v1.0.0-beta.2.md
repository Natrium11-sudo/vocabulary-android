# Vocabulary 1.0.0 Beta 2

The second public beta of **Vocabulary**, a local-first vocabulary trainer for
Android.

## What's new

- **Flexible session goals.** A round no longer has to be 5, 10, 15 or 20
  words. Choose **All** to practice a complete folder or every word of a
  language, or enter **any custom number** between 2 and the number of
  available words.
- **MIT license.** The project is now released under the MIT license; the full
  text is in `LICENSE`.
- Everything from Beta 1, including the vocabulary library with folders, four
  study modes, the two-correct-answers mastery rule, streaks, the study
  calendar and focus mode.

## Install

1. Download `Vocabulary-1.0.0-beta.2.apk` below.
2. Allow installation from unknown sources for your browser or file manager.
3. Open the APK and install it.

Updating from Beta 1 works without uninstalling: both APKs use the same
application ID and the same beta signing key, and your words and progress are
kept.

Requires Android 8.0 (API 26) or newer.

## Beta notes

- This APK is signed with a local Android debug key for beta testing. It is not
  Play Store-ready.
- The interface is available in German and English only.
- The first launch adds a 32-word starter deck so a round can start immediately.
- All words, folders and progress stay in a local Room database.
