# Vocabulary 1.0.0 Beta 1

The first public beta of **Vocabulary**, a local-first vocabulary trainer for
Android.

## Highlights

- All vocabulary grouped by language, with words from every folder in one view.
- Create folders, assign words, filter by folder and search the whole library.
- Four study modes: both directions, each as multiple choice or typing.
- Two-correct-answers-in-a-row mastery rule with XP and a daily goal.
- Daily streak, weekly overview and a monthly study calendar.
- Focus mode using Android screen pinning.
- German/English interface, light/dark/system theme and three mascots.
- No account, ads, analytics or internet permission.

## Install

1. Download `Vocabulary-1.0.0-beta.1.apk` below.
2. Allow installation from unknown sources for your browser or file manager.
3. Open the APK and install it.

Requires Android 8.0 (API 26) or newer.

## Beta notes

- This APK is signed with a local Android debug key for beta testing. It is not
  Play Store-ready.
- The interface is available in German and English only.
- The first launch adds a 32-word starter deck so a round can start immediately.
- All words, folders and progress stay in a local Room database.
